# AWS Steps

1. Create IAM User
2. Create Key Pair
3. Launch EC2
4. Install Java
5. Install MySQL (local for learning) or create RDS
6. Deploy Spring Boot JAR
7. Configure Security Group
8. Test Application
9. Create S3 Bucket
10. Create IAM Role for EC2
11. Upload Files to S3
12. Create ALB
13. Create Auto Scaling Group
14. Configure CloudWatch Alarm
